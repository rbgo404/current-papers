# AgentNoiseBench: Benchmarking Robustness of Tool-Using LLM Agents Under Noisy Condition

- **Authors:** Ruipeng Wang, Yuxin Chen, Yukai Wang, Chang Wu, Junfeng Fang, Xiaodong Cai, Qi Gu, Hui Su, An Zhang, Xiang Wang, Xunliang Cai, and Tat-Seng Chua

- **PDF:** [Original on arXiv, version 1](https://arxiv.org/pdf/2602.11348v1)

## Short note

AgentNoiseBench evaluates tool-using agents under user noise and tool noise. It introduces controllable perturbations into existing agent benchmarks while aiming to preserve task solvability, exposing robustness gaps that clean evaluations can miss.
