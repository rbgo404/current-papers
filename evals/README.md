# Evals

Papers on evaluating agents, generating benchmarks, and constructing verifiable training environments.

- [TASTE](TASTE.md): Generates benchmark tasks from tool sequences, then increases coverage and difficulty.
- [AutoGym](AutoGym.md): Generates tasks, executable environments, and verifiers from a blueprint.
- [AgentNoiseBench](AgentNoiseBench.md): Evaluates tool-using agents under controllable user and tool noise.
- [AgentAbstain](AgentAbstain.md): Paired act/abstain evaluations. **Currently reading** (started 2026-11-12).
