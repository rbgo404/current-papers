# To be read

Reading queue for papers on difficult LLM and agent evaluations. Added November 11, 2026.

- [ ] [ToolMaze](ToolMaze.md): Dependency-graph tasks with explicit or implicit, transient or permanent tool failures test recovery and replanning.
- [ ] [BBEH](BBEH.md): Harder counterparts to BIG-Bench Hard tasks use rule precedence, reconstruction, dependencies, and distractors.
- [ ] [AgentAbstain](AgentAbstain.md): Controlled changes create paired cases where the correct behavior flips between acting and abstaining.
- [ ] [GSM-Symbolic](GSM-Symbolic.md): Symbolic variants and plausible but irrelevant clauses probe robustness of mathematical reasoning.
- [ ] [MultiChallenge](MultiChallenge.md): Adversarially selected multi-turn conversations test constraint retention, contextual inference, version editing, and consistency.
- [ ] [AutoBencher](AutoBencher.md): Iterative search over dataset descriptions uses evaluation feedback to find difficult and informative question categories.
- [ ] [BreakingWeb](BreakingWeb.md): Matched clean/intervention browser tasks keep instructions and success criteria fixed while changing the environment.

[AgentNoiseBench](../evals/AgentNoiseBench.md) remains in `evals/` as the separately selected paper. Entries link to original papers and PDFs rather than storing copies. No reading completion dates are assumed.
